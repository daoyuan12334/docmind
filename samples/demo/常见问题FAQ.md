# DocMind 常见问题（FAQ）

## 关于使用

**问：上传后多久能检索到？**
文档上传后进入异步流水线，通常 10 秒内完成解析与向量化。
大文件（超过 20MB）或扫描件需要 OCR 的页面较多时可能需要 1～3 分钟，
可在文档管理页查看进度条与状态。

**问：同一个文档重复上传会怎样？**
系统按内容 SHA-256 做幂等判断，同一知识库内相同内容不会重复处理，
连点上传也只会跑一次流水线，不会产生重复切片。

**问：为什么问某个问题答不上来？**
答案严格基于已索引的文档上下文生成。如果知识库里确实没有相关内容，
系统会明确回答"未提及"，而不是编造。
可先到检索实验室用关键词验证是否召回了对应切片。

**问：支持哪些语言？**
界面为中文。文档内容与提问支持中英文，检索对中文做了 bigram 分词优化。

## 关于部署

**问：能否完全离线运行？**
模型部分需要对接大模型服务。若企业已部署本地模型服务且兼容 OpenAI 接口，
修改 AI_BASE_URL 指向内网地址即可，文档原文始终不出企业网络。

**问：向量库一定要 PostgreSQL 吗？**
不是。开发环境可用内置的内存向量库（SimpleVectorStore）持久化到本地 JSON，
生产建议使用 PostgreSQL + pgvector 以获得更好的并发与查询性能。

**问：没有 Kafka 能不能跑？**
能。系统通过 MessageBus 端口抽象，无 Kafka 时使用本地内存总线，
功能完整，只是异步流水线不具备跨实例分发与堆积缓冲能力。

## 关于权限

**问：谁能看到我的知识库？**
知识库按创建者隔离，管理员可查看全部。通过 MCP 对外开放时，
需要在配置中显式把知识库 ID 加入白名单，未加入的不会被外部访问到。

**问：MCP 端点安全吗？**
配置 docmind.mcp.api-key 后，所有 MCP 请求必须携带 X-MCP-ApiKey 头，
未携带或错误一律返回 401。建议同时限制来源 IP。

## 关于配额

**问：有使用限制吗？**
可按用户配置每日 token 配额与每分钟请求数，超出后返回 429。
管理员可在运维管理页查看各用户的用量与配额消耗。
