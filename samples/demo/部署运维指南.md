# DocMind 部署运维指南

## 环境要求

| 组件 | 版本 | 备注 |
| --- | --- | --- |
| JDK | 21 及以上 | 已在 21 与 25 上验证 |
| Maven | 3.9 及以上 | 构建用 |
| PostgreSQL | 16 + pgvector | 生产向量库 |
| Redis | 7 | 缓存与限流 |
| Kafka | 3.x（KRaft） | 异步流水线，可选 |
| MinIO | 最新 | 对象存储，可选 |
| Node.js | 20 及以上 | 前端构建 |

## 快速启动（开发环境）

```bash
cd docmind
cp .env.example .env      # 填入模型密钥
./tool/dev.sh --build     # 打包并启动，零外部依赖
```

服务默认监听 8080，H2 文件库落在 backend/data，向量库落在 data/vector-store.json。

## 生产部署

```bash
docker compose -f docker-compose.yml up -d
```

compose 已编排 postgres、redis、kafka、minio、backend、frontend、prometheus、grafana。
首次启动需先执行 deploy/init 下的 SQL 初始化扩展与表结构。

## 配置项说明

| 变量 | 说明 | 默认值 |
| --- | --- | --- |
| DASHSCOPE_API_KEY | 模型服务密钥 | 无，必填 |
| AI_BASE_URL | OpenAI 兼容端点，需自带 /v1 | 百炼兼容模式地址 |
| AI_CHAT_MODEL | 对话模型 | qwen-plus |
| AI_EMBEDDING_MODEL | 向量模型 | text-embedding-v4 |
| AI_EMBEDDING_DIM | 向量维度，须与模型一致 | 1024 |
| DOCMIND_MCP_API_KEY | MCP 鉴权密钥，留空则不鉴权 | 空 |
| DOCMIND_MCP_EXPOSE_KB_IDS | MCP 可访问的知识库白名单 | 空（全部拒绝） |
| JWT_SECRET | JWT 签名密钥，生产必须 32 字节以上随机串 | 内置，务必替换 |
| DAILY_TOKEN_QUOTA | 每用户每日 token 配额 | 200000 |
| RPM_LIMIT | 每用户每分钟请求数 | 30 |

## 常见故障排查

**后端启动报端口被占用**
检查环境变量 SERVER__PORT 是否被意外注入，Spring Boot 宽松绑定会把它当成 server.port。
启动脚本里已显式清空该变量并强制 --server.port。

**上传一直卡在 PARSING**
多为多模态模型调用超时，检查 AI_VISION_MODEL 是否可用、密钥是否有效。
扫描件 PDF 尤其依赖视觉模型。

**检索召不回中文**
确认中文分词通道是否启用，可在检索实验室先用短关键词验证关键词通道是否返回结果。

**MCP 调用返回 401**
确认请求头用的是 X-MCP-ApiKey（不是 X-Api-Key），且值与配置一致。

## 备份

需要备份的内容：PostgreSQL 数据、MinIO 桶中的原始文件、backend/data（开发模式下）。
向量库可由文档重新生成，但重新向量化会产生模型调用费用。
