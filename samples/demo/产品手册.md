# DocMind 产品手册

## 产品定位

DocMind 是面向企业内部的私有文档智能系统，解决"文档散落在各处、搜索找不到、新人问老员工"的问题。
所有数据存储在企业自有的基础设施中，文档原文不出内网，模型调用可替换为本地部署或私有云模型。

## 核心功能

### 文档摄取
支持 PDF、Word（doc/docx）、Excel（xls/xlsx）、PPT（pptx）、纯文本、Markdown、图片（png/jpg）、
扫描件 PDF、音频（wav/mp3）、视频（mp4）共十大类格式。

上传后进入异步流水线：PENDING → PARSING → CHUNKING → EMBEDDING → INDEXED，
任一环节失败会进入 FAILED 并支持重试，重试耗尽后进死信队列由人工介入。

### 解析策略
- 文本型 PDF：抽取文本层，按标题与段落智能切分
- 扫描件 PDF：文本层为空时自动降级为视觉 OCR，逐页送视觉模型识别
- Excel：每个工作表转成 Markdown 表格，表头保留
- PPT：按页切片，保留页码与标题层级
- 图片：送视觉模型做内容描述
- 音频：全模态模型转写为文本
- 视频：ffmpeg 抽关键帧，逐帧送视觉模型后合并时序摘要

### 检索与生成
采用向量检索与关键词检索双通道，用 RRF（Reciprocal Rank Fusion，k=60）融合排序，
向量通道权重 0.65、关键词通道权重 0.35。中文查询使用 bigram 分词提升召回。

生成阶段强制"只依据检索到的上下文作答"，答案中带 [n] 形式的引用标注，
点击可回溯到原始文档与切片。上下文未覆盖时明确说明"未提及"，不编造。

### 多模态问答
除文本提问外，可直接上传图片或语音提问。图片走视觉模型理解，
语音先转写再与知识库检索结果合并作答。

### MCP 开放能力
内置 MCP Server（Streamable HTTP，端点 /mcp），对外暴露四个工具：
list_knowledge_bases、search_knowledge_base、ask_knowledge_base、get_document_summary。
可配置知识库白名单与独立鉴权密钥，未授权的知识库一律拒绝。

## 部署形态

| 形态 | 说明 |
| --- | --- |
| 单机开发 | H2 + 内存向量库 + 本地磁盘 + 内存消息总线，零外部依赖 |
| 标准生产 | PostgreSQL + pgvector + Redis + MinIO，单机可承载中小团队 |
| 完整生产 | 上述组件 + Kafka 异步流水线，适合文档量大、并发高的场景 |

## 性能与容量建议

单文档建议不超过 50MB，单页 PDF 建议不超过 100 页。
日均摄取量在 5000 文档以内时，2 核 4G 的后端实例即可满足。
