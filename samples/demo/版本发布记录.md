# DocMind 版本发布记录

## 版本命名规则

采用 `主版本.次版本.修订号`（语义化版本）：
- 主版本：存在不兼容的架构变更或数据迁移
- 次版本：新增功能，向后兼容
- 修订号：缺陷修复与安全补丁，无功能变更

发布节奏：修订号按需发布；次版本每 6 周一个迭代；主版本每年不超过一次。

---

## v2.4.0（2026-09-28）— 当前版本

### 新增
- MCP Server 升级到 Streamable HTTP 传输，协议版本 2025-06-18
- 新增工具 `get_document_summary`，支持按文档 ID 获取结构化摘要
- 知识库白名单支持多 ID 配置，未授权知识库一律拒绝
- 检索实验室页面新增"仅关键词""仅向量""混合"三种模式对比
- 上传页新增多模态附件问答（图片 / 语音提问）

### 优化
- 中文分词由单字改为 bigram，长尾名词召回率提升约 18%
- 摄取流水线进度改为按阶段细分，前端可看到 PARSING / CHUNKING / EMBEDDING
- 切片重叠由固定 100 字改为按段落边界自适应，减少跨段截断

### 修复
- 修复扫描件 PDF 文本层为空时未降级 OCR 的缺陷
- 修复并发上传同一文件时死信队列重复入队
- 修复指标端点在首次调用前不返回业务指标的问题（懒注册导致告警静默失效）

### 已知问题
- 单文档超过 100 页时 OCR 阶段耗时较长，建议先做页码拆分
- MP3 格式音频在部分采样率下转写准确率下降，建议统一转 16kHz WAV

## v2.3.0（2026-08-15）

### 新增
- 引入混合检索 RRF 融合，替代原先的加权求和
- 支持 Kafka 异步流水线，摄取吞吐提升约 4 倍
- 新增用量统计页与配额管理（按用户 / 按知识库两个维度）

### 修复
- 修复 Redis 连接池耗尽后摄取任务静默丢失
- 修复知识库删除后向量数据未清理

---

## v2.2.0（2026-07-03）

### 新增
- 支持 PPT 按页切片并保留页码与标题层级
- 支持视频抽关键帧后做视觉理解
- SSE 流式问答，`meta` 事件携带引用来源

### 修复
- 修复前端 SSE 解析不兼容无空格帧的问题（Spring 输出 `event:meta` 不带空格）
- 修复 Excel 多工作表只解析第一张表

---

## v2.1.0（2026-05-20）

### 新增
- 六边形架构重构，中间件全部下沉为适配器
- dev profile 零外部依赖启动（H2 + 内存向量 + 本地磁盘）

### 修复
- 修复 PDF 加密文档解析直接抛异常未进 FAILED

---

## v2.0.0（2026-03-11）— 架构升级

- 后端升级至 Spring Boot 4 / Spring AI 2.0 / JDK 21
- 数据库由 MySQL 迁移至 PostgreSQL + pgvector，向量检索下沉到数据库
- 前端由 Vue 2 迁移至 Vue 3 + Vite
- **不兼容变更**：v1.x 的向量数据需执行迁移脚本 `tool/migrate-v1-v2.sql` 后重建索引
